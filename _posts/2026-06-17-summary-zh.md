## [IIS 服务器遗留的 8.3 文件名漏洞被重新审视以用于安全研究。](https://mll.sh/humiliating-iis-servers-for-fun-and-jail-time/) ⭐️ 7.0/10

文章重新审视了 IIS 服务器中与从 DOS 继承的 8.3 文件名约定相关的遗留漏洞，该漏洞可以通过 HTTP 请求中的波浪号（~）字符泄露内部文件和文件夹名称。 此漏洞意义重大，因为它在现代 Windows 系统上仍然存在，如果被利用，攻击者可以枚举服务器上的敏感文件，可能导致进一步的入侵。 一个关键细节是，在 Windows 的 C:驱动器上（IIS 的默认 Web 根目录 `C:\Inetpub` 所在地），8.3 文件名生成是默认启用的，而在 Windows 10/11 的其他驱动器上默认禁用，并且可以通过注册表键禁用 8.3 文件名来缓解此漏洞。

hackernews · denysvitali · Jun 16, 22:53 · [社区讨论](https://news.ycombinator.com/item?id=48563394)

**背景**: 8.3 文件名约定是来自 DOS 和早期 Windows 的遗留系统，它将文件名限制为八个字符加三个字符的扩展名，为兼容性创建长文件名的“短名称”版本。在 IIS 中，这会产生一个漏洞，其中波浪号字符（~）后跟一个数字可以用来猜测文件和文件夹的短名称，这种技术称为 IIS 波浪号枚举。这使得攻击者可以发现未直接链接或本不打算公开的文件。

## [《量子杂志》探讨基本粒子数量的模糊性](https://www.quantamagazine.org/how-many-elementary-particles-are-there-really-20260615/) ⭐️ 6.0/10

这篇文章以科普形式探讨了基本粒子有多少个的问题，指出如果考虑理论构建，合理的答案从标准模型的 17 种粒子到接近 996 种不等。 这揭示了物理学中一个根本性的矛盾，即我们经过充分检验的标准模型与提出更多实体的理论扩展之间的张力，影响着我们对宇宙基本构建单元的理解。 粒子数量因框架不同而有很大差异：标准模型列出 17 种基本粒子，但若包含量子色动力学中的复合粒子（如强子）或超越标准模型的假想粒子，数量可接近 996。

rss · Quanta Magazine · Jun 15, 15:07

**背景**: 粒子物理的标准模型是描述基本粒子及其相互作用的主导理论，将其分为夸克、轻子、规范玻色子和希格斯玻色子。量子色动力学（QCD）是标准模型内解释将夸克结合成质子和中子等复合粒子（称为强子）的强相互作用的理论。像大统一理论或超对称这样的理论扩展提出了尚未观测到的额外粒子，这使“基本”实体的简单计数变得复杂。
