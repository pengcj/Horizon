## [Quantinuum Helios：一台 98 量子比特离子阱量子计算机实现全连接](https://www.nature.com/articles/s41586-026-10676-4) ⭐️ 9.0/10

全新的 Quantinuum Helios 量子处理器是一台基于量子电荷耦合器件（QCCD）架构构建的 98 量子比特系统，其性能已超越经典计算机的能力，为未来的量子计算发展提供了可扩展的路径。 这一突破标志着向实用化大规模量子计算迈出的重要一步，它证明了高量子比特数系统能够维持超越经典模拟的性能，可能加速量子优势在实际问题中的实现。 该处理器具备量子比特之间的全连接特性，这消除了对嘈杂的 SWAP 门的需求，并能更高效地实现量子纠错码，这是构建容错量子计算机的关键特性。

## [梳水母研究揭示了动物多细胞演化历程中的关键信号通路](https://www.nature.com/articles/s41586-026-10643-z) ⭐️ 9.0/10

一项发表于《自然》杂志的研究发现，梳水母 Mnemiopsis leidyi 具有胚孔组织者这一结构，该结构由一个核心信号通路驱动，而此前认为该通路在栉水母动物中并不存在。这一发现表明，该信号通路可能是动物向多细胞生命形式过渡的关键创新。 这一发现挑战了既有的演化模型，表明用于组织身体轴线的信号机制出现的时间远比之前认为的要早，可能早于主要动物谱系的分化。这为我们理解生物学中最古老的问题之一——多细胞动物最初如何演化而来——提供了根本性的见解。 这项研究通过比较梳水母 Mnemiopsis leidyi 与海葵 Nematostella vectensis 的实验，鉴定出两者中都存在一个保守的、与胚孔组织者相关的 Wnt/β-catenin 信号通路，尽管它们在演化上相距甚远。

rss · Nature · Jun 17, 00:00

**背景**: 胚孔组织者是早期动物胚胎中一个关键的信号中心，负责建立身体的主轴；它的起源一直是演化发育生物学的核心议题。栉水母动物（即梳水母）是一个海洋动物门，其在演化树上相对于其他动物（如海绵和刺胞动物）的位置一直存在高度争议。海葵 Nematostella vectensis 是一个成熟的模式生物，用于研究非两侧对称动物的发育演化。

## [RFC 10008 定义了新的 HTTP QUERY 方法以处理复杂查询](https://www.rfc-editor.org/info/rfc10008/) ⭐️ 8.0/10

IETF 发布了 RFC 10008，正式定义了新的 HTTP QUERY 方法。该方法允许客户端发送包含复杂查询参数的请求体，同时保持安全和幂等的语义。 这项标准解决了长期以来 GET 请求不能包含请求体、而 POST 请求又非幂等的限制，为 Web API 中的搜索和过滤操作提供了更清晰的解决方案。它可能显著影响未来的 API 设计模式、缓存策略和 Web 框架实现。 其关键特性是 QUERY 请求被定义为既安全（只读）又幂等（多个相同请求与一个请求效果相同），类似于 GET 但支持请求体。规范还引入了 Accept-Query 响应头，以帮助客户端了解服务器接受的查询格式。

hackernews · schappim · Jun 17, 10:51 · [社区讨论](https://news.ycombinator.com/item?id=48568502)

**背景**: HTTP 方法定义了请求的语义，其中 GET 是安全且幂等的，用于检索资源；而 POST 用于创建或处理数据，但不提供这些保证。幂等方法意味着发出多个相同请求对服务器的效果与发出单个请求相同，这对于可靠的网络操作至关重要。这种新方法填补了无法轻易在 URL 查询字符串中表达的复杂查询的特定空白。
